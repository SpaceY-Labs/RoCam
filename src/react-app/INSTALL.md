# Frontend Install Guide

Author: Zifan Si  
Date: 2026-04-05  
Purpose: Provides a concise installation and startup procedure for the React frontend workspace.

## Steps

1. Open a terminal in the repository root.
2. Move into the frontend workspace:

```bash
cd src/react-app
```

3. Install dependencies:

```bash
yarn
```

4. Start the development server:

```bash
yarn dev
```

5. Open the local URL printed by Vite in your browser.

## Optional Commands

Build the production bundle:

```bash
yarn build
```

Run unit tests:

```bash
yarn test
```

Run coverage:

```bash
yarn test:coverage
```

Run linting:

```bash
yarn lint
```
