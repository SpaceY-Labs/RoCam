SiamMask-Lite Architecture

Visual-Query Real-Time Object Segmentation for RoCam — Designed for Jetson Orin Nano @ 60fps

System Overview — YOLO vs SiamMask-Lite

Current: YOLO (Text-Class Detection)

  • Detects fixed classes: "rocket", "airplane", etc.
  • Cannot track specific objects by appearance
  • No segmentation mask (bounding box only)
  • If two rockets in frame — can't distinguish them
  • Requires retraining for new object types

New: SiamMask-Lite (Visual-Query Segmentation)

  • Input: image of target object (not text label)
  • Tracks the specific object matching the reference
  • Outputs pixel-level segmentation mask
  • Distinguishes between similar objects by appearance
  • Zero-shot: works on any object without retraining

Model Statistics

Total: ~600K params Backbone: ~300K Correlation: ~150K Decoder: ~150K FP16 Size: ~1.2MB

For comparison: YOLO11n has 2.6M params, MobileNetV2 has 3.4M, ResNet-50 has 25M. Our model is ~4x smaller than YOLO11n because we only need to match features, not classify 80+ classes.

3-Phase Training Strategy

1
Pre-training: YouTube-VOS + DAVIS
50 epochs, LR=1e-3, batch=32  |  Teaches general ability to match and segment any object. ~65K video clips with pixel-level masks across diverse object categories. The model learns visual similarity matching without any rocket-specific knowledge.
2
Domain Adaptation: YOLO BBox Pseudo-Masks
30 epochs, LR=1e-4, batch=16  |  Uses your existing YOLO bounding box annotations converted to rectangular pseudo-masks. Mixes 70% rocket data + 30% VOS data to adapt to your domain without catastrophic forgetting. Backbone frozen for first 10 epochs.
3
Precision: Real Mask Annotations on Rockets
20 epochs, LR=5e-5, batch=8  |  Fine-tune on your hand-labeled or SAM-assisted pixel-perfect mask annotations on rocket footage. Increased mask loss weight (2x) for sharp segmentation boundaries. Even 200-500 annotated frames can significantly improve mask quality.

How to Collect Mask Training Data

Option A: SAM-Assisted (Recommended)

Use Segment Anything Model (SAM) to auto-generate masks from your YOLO bboxes, then manually correct the ~10% that are wrong. This gives you thousands of masks with ~2 hours of work.

pip install segment-anything

Option B: CVAT / LabelMe

Manual polygon annotation on video frames. Slower but highest quality. Focus on: silhouette edges, exhaust plume boundaries, staging events. Target 500+ annotated frames across diverse conditions.

Option C: Your Labelling App

You already have a labelling app in src/labelling-app/ — extend it with polygon/brush mask tools. This keeps your pipeline self-contained.

Option D: GrabCut from BBoxes

OpenCV GrabCut can auto-segment within bounding boxes. Quality is lower than SAM but requires zero manual work. Good as a Phase 2 bridge before you have real masks.

Integration with Existing RoCam Pipeline

The SiamMask tracker replaces the nvinfer YOLO detection in your GStreamer pipeline. Instead of class-based detection, the operator selects a target via the web app, and the tracker follows it.

ComponentCurrent (YOLO)New (SiamMask-Lite)
Detection nvinfer + YOLO .engine TensorRT tracking_engine.engine
Input Text class: "rocket" Image crop of target (from web app click)
Output Bounding box only Pixel mask + bbox + confidence
Multi-object Detects all rockets (can't distinguish) Tracks the specific clicked object
Speed ~5ms per frame ~12ms per frame (60fps capable)
Initialization None (always detecting) One-time template encoding (~5ms)

Quick Start

# 1. Download YouTube-VOS and DAVIS datasets
mkdir -p data && cd data
# YouTube-VOS: https://youtube-vos.org/dataset/vos/
# DAVIS 2017: https://davischallenge.org/davis2017/code.html

# 2. Phase 1: Pre-train on VOS data (desktop GPU, ~12 hours on RTX 3080)
python -m siammask.training.train \
    --phase 1 \
    --vos-root data/youtube-vos/train data/DAVIS/trainval \
    --epochs 50 --batch-size 32 --lr 1e-3

# 3. Phase 2: Fine-tune with your YOLO rocket data
python -m siammask.training.train \
    --phase 2 \
    --checkpoint checkpoints/phase1_best.pth \
    --yolo-images data/rockets/images/train \
    --yolo-labels data/rockets/labels/train \
    --vos-root data/youtube-vos/train \
    --epochs 30 --batch-size 16 --lr 1e-4

# 4. Export to TensorRT (on Jetson)
python -m siammask.inference.export_tensorrt \
    --checkpoint checkpoints/phase2_best.pth \
    --output-dir engines/ --fp16

# 5. Benchmark on Jetson
python -m siammask.inference.tracker --model checkpoints/phase2_best.pth --benchmark
